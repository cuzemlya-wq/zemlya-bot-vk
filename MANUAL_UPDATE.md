# Инструкция по ручному обновлению бота

## Способ 1: Автоматический скрипт (рекомендуется)

```bash
# 1. Подключитесь к серверу по SSH
ssh user@your-server-ip

# 2. Перейдите в папку с ботом
cd /path/to/zemlya-bot-vk

# 3. Запустите скрипт обновления
./UPDATE_BOT.sh
```

Скрипт автоматически:
- Остановит старый процесс бота
- Загрузит новый код с GitHub
- Запустит бота заново

---

## Способ 2: Ручное обновление

```bash
# 1. Остановите бота
pkill -f 'python.*bot_main'

# 2. Обновите код
git fetch origin
git reset --hard origin/main

# 3. Запустите бота
nohup python3 -m src.bot_main > bot.log 2>&1 &

# 4. Проверьте логи
tail -f bot.log
```

---

## Проверка работы бота

Отправьте в VK боту:
```
Справочник ЗОУИТ
```

Бот должен ответить со справочником ЗОУИТ.

---

## Где может быть запущен бот?

1. **Railway** - автоматический деплой при push
2. **Timeweb** - ручной запуск через SSH
3. **PythonAnywhere** - ручной запуск через веб-консоль

Если Railway не обновляет бота автоматически, подключитесь к Timeweb и выполните UPDATE_BOT.sh
